# Stefcraft

Здесь выходят тестовые сборки игры и лаунчера Stefcraft для macOS и Windows.

[Скачать последнюю версию](https://github.com/orbitastef/Stefcraft-Releases/releases/latest)

- Скачайте архив **Stefcraft-Launcher** для своего компьютера и распакуйте его.
- Откройте лаунчер, нажмите «Скачать и установить», затем «Играть».
- Следующие обновления появятся в лаунчере. Для запуска уже установленной игры интернет не нужен.

Тестовая сборка для macOS подписана локально. Действия при предупреждении
Gatekeeper описаны в [справке Apple](https://support.apple.com/en-us/102445).
